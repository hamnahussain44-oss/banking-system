# Banking System

A console-based Java application for managing bank accounts.

**Features:**
- Create accounts, protected by a PIN set at creation
- Deposit and withdraw funds, with PIN verification required for both
- View account details and full transaction history (also PIN-protected)
- Prevents duplicate account numbers and invalid transaction amounts

**Built with:** Java (core OOP, collections, PIN-based authentication)

**To run:**
javac src/*.java
java -cp src Main
